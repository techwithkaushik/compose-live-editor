# On-device Compose source interpreter

## First active engine milestone

The app now parses a bounded declarative Kotlin/Compose subset locally and renders the resulting immutable tree using the app's real Compose runtime. It does not invoke Kotlin/JVM compilation, load generated bytecode, or execute arbitrary Kotlin.

Supported source shape:

- One top-level `@Composable fun Name() { ... }` entry point.
- Optional `package` and `import` declarations before the entry point.
- `Column { ... }`, `Row { ... }`, and `Box { ... }` layout calls.
- `Text("literal")` and `Text(text = "literal")`.
- `Button(onClick = { ... }) { ... }` with declarative child content.

The first milestone intentionally does not execute callback bodies, variables, expressions, modifiers, themes, or arbitrary Kotlin. A button is rendered with a real clickable Compose surface but its user callback is not evaluated yet. Unsupported syntax reports line/column diagnostics. Limits are 64 KiB source, 32 nesting levels, and 512 nodes.

## Why this route

The previous ART compiler spike cannot execute the stock Kotlin/JVM compiler because ART lacks `java.lang.management.ManagementFactory`. This interpreter does not load or patch Java SE classes and does not use Termux or a remote compiler. It is an incremental, explicitly limited preview engine—not a claim of full Kotlin language compatibility.

## Next engine gates

1. Expand parser fixtures for additional Material3 form components and malformed nesting.
2. Add typed form-state rendering and safe literal/state expression evaluation.
3. Add broader modifier and common Material3 component support.
4. Add incremental parsing and debounce for edit-to-preview latency.
5. Decide whether to expand the interpreter or revive a separately validated Android-compatible compiler backend for general Kotlin.
6. Validate the production APK on armeabi-v7a hardware; measure memory and latency.

The preview screen must continue to show a source-located error for unsupported code. Never replace an unsupported user program with a canned preview.
